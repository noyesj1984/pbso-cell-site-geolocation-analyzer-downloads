# PBSO Cell Site and Geolocation Analyzer

Maps Timing Advance, calls & texts and data sessions from carrier records on a map with a timeline, analytics,
points of interest and animation, and exports KMZ files for Google Earth.

## Download

**[Get the latest version](../../releases/latest)**, then pick the zip for your computer:

| Computer | File |
|---|---|
| Windows 10 / 11 | PBSO-Cell-Site-Geolocation-Analyzer-Windows.zip |
| Mac with Apple chip (M1 and newer) | PBSO-Cell-Site-Geolocation-Analyzer-Mac.zip |

No installation, admin rights or Python needed.

**Windows:** unzip into a folder you own (e.g. Documents), open the folder and double-click
**PBSO Cell Site and Geolocation Analyzer.exe**. First time only: "Windows protected your PC" → **More info** → **Run anyway**.

**Mac:** unzip, drag **PBSO Cell Site and Geolocation Analyzer.app** to Applications (or any folder) and double-click it.
First time only: **System Settings → Privacy & Security** → scroll down → **Open Anyway**.

The app is not code-signed, which is why these one-time warnings appear.

## Updates

The app checks for a new version when it starts. When one is out, an **Update to x.y.z** button appears at the top;
**Install update** downloads it, closes the app, swaps in the new version and opens it again. Your tower lists,
settings and case data are kept. You can turn the check off, or check now, under **Settings → Updates**.
